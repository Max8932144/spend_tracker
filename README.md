# Сервис «Трекер трат» (RESTful API) 

Проект представляет собой HTTP-сервер с RESTful API для учета личных расходов.

## Спецификация эндпоинтов

| Название действия                           | Локация (URL)                     | Тип запроса | Описание запроса и ответа                                                                                                                                                                               |
| :------------------------------------------ | :-------------------------------- | :---------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Добавить новую трату                        | `/expenses`                       | **POST**    | **Запрос:** JSON `{"category": "Еда", "amount": 500, "date": "2026-10-27"}`. Обязательные поля: `category`, `amount`, `date`.<br>**Ответ:** `201 Created`. JSON с добавленной тратой и уникальным `id`. |
| Получить список трат                        | `/expenses`                       | **GET**     | **Запрос:** Без параметров. Возвращает все траты.<br>**Ответ:** `200 OK`. JSON-массив объектов трат.                                                                                                    |
| Получить категорию с макс. тратами за месяц | `/expenses/statistics/categories` | **GET**     | **Запрос:** Query-параметр `?month=2026-10`.<br>**Ответ:** `200 OK`. JSON `{"category": "Еда", "total_amount": 5000}` (категория с наибольшей суммой за месяц).                                         |
| Получить самую крупную трату за месяц       | `/expenses/statistics/max`        | **GET**     | **Запрос:** Query-параметр `?month=2026-10`.<br>**Ответ:** `200 OK`. JSON `{"id": 1, "amount": 5000, "category": "Еда", "date": "2026-10-27"}`.
